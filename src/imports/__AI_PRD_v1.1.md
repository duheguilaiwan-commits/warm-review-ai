# 暖评 AI (EduVibe) 产品需求文档 · MVP V1.1（提交 Figma Make 设计用）

**文档状态：** 需求已对齐定稿 | **产品形态：** 移动端响应式 Web App（iOS / Android 浏览器，375px 基准）| **提交对象：** Figma Make（UI 设计） + 研发团队（实现）
**产品代号：** EduVibe ｜ **中文名：** 暖评 AI ｜ **主色：** 暖橙 `#F97316` ｜ **底色：** 暖奶油 `#FFF8F3`

---

## 0. 一句话定位
一款面向**全品类教培工作者**的「轻量化、高情商 AI 点评生产力工具」：把一次课后反馈的撰写时间从 3 分钟压缩到 30 秒内，输出家长/学员愿意读、老师敢转发的高情商点评。

---

## 1. 目标用户

| 角色 | 画像 | 典型诉求 |
|---|---|---|
| **一线教师（核心）** | K12 语数外 / 理科 / 文科、素质艺术（美术/音乐/体育）、成人教育（考研/考证/职场技能）的全科老师 | 每节课后都要给多名学生写反馈；负面反馈难拿捏分寸；讨厌"机器味"套话 |
| **教务助理 / TA（增长）** | 机构里需高频统管多学科、批量处理反馈的教务人员 | 批量产出、效率优先；用量大，是 PLG 转化的核心对象 |

**用户特征（设计语气参考）：** 非技术背景、移动端碎片化使用、习惯微信发消息、重视"像人说的话"。

---

## 2. 使用场景

1. **课间 30 秒快评**：老师下课拿出手机，选学生 → 点几个标签 → 选星级 → 写一句话 → 点生成 → 复制发家长微信。
2. **素质/艺术课点评**：美术老师给学员作品写点评，需要肯定创意又指出技法问题，语气要温柔专业。
3. **成人/考研督学**：给成年学员发口语化语音脚本，像朋友一样提醒进度。
4. **机构批量场景**：教务助理一天给几十名学生产出，触发 L3 限流 → 引导加微信开专属通道。
5. **体验式试用**：未注册用户点"一键体验"直接进产品，零配置感受效果（首版主路径）。

---

## 3. 核心转化动作（Core Conversion Action）

### 3.1 产品主闭环（价值转化）
```
登录/体验 → 选择或新建学生 → 打卡输入（标签 + 星级 + 一句话事实）
        → 一键「生成反馈」 → 流式产出双模态文案 → 一键复制 / 换个说法
```
**目标：** 让老师 30 秒内拿到一条"可直接发送"的高情商点评。这是产品的唯一核心价值动作。

### 3.2 PLG 增长转化（商业化漏斗）
- **L1 匿名 IP**：20 次/天，硬阻断（403）。
- **L2 注册账号**：200 次/天，满足 95% 独立教师日常。
- **L3 机构超频（第 201 次）**：柔性阻断（429），弹窗引导 **「加开发者微信 Surge_forward_，免费开大容量专属通道」**。
L3 弹窗是产品的核心增长转化动作，文案需高转化、温暖、不骚扰。

## 4. 信息架构与页面清单（共 4 个屏幕）

| # | 屏幕 | 作用 | 是否首屏 |
|---|---|---|---|
| 1 | **登录页** | 品牌展示 + 一键体验登录（邮箱入口隐藏） | 是（未登录） |
| 2 | **学生列表页（首页）** | 学生卡片列表、新建/编辑、档案入口 | 是（已登录） |
| 3 | **打卡页** | 标签矩阵 + 双维度星级 + 无极文本框 → 生成 | 否 |
| 4 | **结果页** | 双模态流式渲染 + 复制/换说法 | 否（生成后） |

> 核心操作不超过 3 个视窗（列表 → 打卡 → 结果）。

---

## 5. 各屏幕详细模块

### 5.1 登录页（Login）
- **顶部品牌区**：暖评 AI 文字 Logo + 一幅轻量线描插画（老师手写 / 对话气泡 / 纸飞机）。
- **中部 Slogan**：例如「把每一句点评，写成孩子愿意听的话」。
- **主操作**：大圆角「一键体验」按钮（深色底白字）。
- **次操作（隐藏）**：邮箱验证码登录入口，默认收起/弱化，仅在配置邮件服务后启用。
- **底部**：极简免责/版本小字。

### 5.2 学生列表页（Home / Student List）
- **顶部固定栏**：品牌名「暖评 AI」+ 极简图标。
- **列表区**：学生卡片纵向排列。
  - 卡片内容：**仅显示学生姓名 + 头像首字圆形徽章**（暖橙浅底）。性格底色**不在列表展示**。
  - 卡片右侧：「档案 ›」小字入口，点击弹出**学生档案弹层**（小字展示性格底色等档案信息）。
  - 点击卡片 → 进入该生打卡页。
- **新建/编辑**：右下角悬浮按钮（FAB，深色或暖橙，≥44px），唤起弹窗录入「姓名 + 性格底色」。
- **空状态**：插画 + 文案「还没有学生，先添加第一位吧」+ 引导按钮。

### 5.3 打卡页（Input）
- **顶部固定导航**：返回箭头 + 学生姓名 + 「档案」小字入口（查看性格底色）。
- **标签区**：横向滑动分类 Tab（隐藏滚动条）：`通用习惯 / 理科表现 / 文科表现 / 素质艺术 / 成人教育`。
  - 每个 Tab 下为标签药丸矩阵，可多选。
  - 末尾固定「+ 自定义标签」药丸，输入后即时加入并持久化。
- **评分区**：两张独立白色卡片，各含：
  - `课堂专注度`（1–5 星，衡量学习态度）
  - `课堂吸收度`（1–5 星，衡量教学效果）
- **文本框**：无极自适应高度卡片，占位符「顺手记下一句话：今天他哪里卡壳了，或者哪里表现得不错…」。
- **底部固定主按钮**：「生成反馈」（深色/暖橙大圆角，≥48px 热区）。
- 生成时显示骨架屏 + 加载动效。

### 5.4 结果页（Output）
- **双模态卡片**：
  - 卡片 A「微信长文」：80–120 字，深灰正文 `#333`，自然换行。
  - 卡片 B「语音脚本」：50–70 字，高度口语化。
  - 文字以**流式打字机**逐字出现，带轻微光标。
- **操作栏**：「一键复制」（主按钮，剪贴板 API + Toast）+「换个说法」（次按钮，带上下文重流式）。
- **返回/再生成**：回到打卡页微调。
- **L3 弹窗（触发时）**：柔性阻断对话框，文案含「加开发者微信 Surge_forward_」+ 微信图标。

## 6. 关键业务规则与数据（设计需体现的真实逻辑）

- **动态标签字典（5 类 30 标签，前端硬编码）**
  - 通用习惯：`上课专注 / 容易走神 / 互动积极 / 作业按时交 / 需要鼓励 / 状态回暖`
  - 理科表现：`计算粗心 / 公式不熟 / 举一反三 / 逻辑清晰 / 审题马虎 / 概念扎实`
  - 文科表现：`词汇量丰富 / 语感不错 / 阅读薄弱 / 表达清晰 / 书写需规范 / 理解深刻`
  - 素质艺术：`色彩大胆 / 透视准确 / 节奏感好 / 练习刻苦 / 动作标准 / 表现力强`
  - 成人教育：`概念扎实 / 论述逻辑散 / 刷题效率高 / 基础薄弱 / 备考状态佳 / 执行力强`
- **双维度星级**：专注度=态度，吸收度=效果，各 1–5 星。
- **文本框**：无极增高、无字数上限、温情占位符。
- **双模态输出**：微信长文 80–120 字 / 语音脚本 50–70 字。
- **历史记忆召回**：生成时读取该生最近一条反馈，增强语气连续性（UI 不需展示，但文案语气应体现连贯）。
- **三级限流 / L3 弹窗**：见 §3.2。

---

## 7. 技术约束（影响 UI 的硬性指标）

- **Mobile-First**：375px 基准宽度，考虑 iOS Safari 底部安全区（Safe Area）与 Android 虚拟按键。
- **操作热区**：Tab、星级、生成/复制按钮点击区 ≥ 44px（主按钮 ≥ 48px）。
- **流式体验**：生成时立即展示骨架屏 + 打字机渲染。
- **滑动 Tab**：隐藏滚动条，平滑切换（参考小红书首页分类栏）。
- **文本框交互**：随内容平滑展开 + 软键盘弹出时 `scrollIntoView` 提升焦点到可视中心。
- **双模态排版**：段落间距舒适，深灰 `#333` 正文（非纯黑）。

## 9. 视觉风格规范（提交设计的硬约束，必须文字化）

### 9.1 整体气质关键词
**温暖 · 轻盈 · 有序 · 可信 · 不费力** —— 像一本干净的教师手账，而非复杂办公软件。

### 9.2 色彩系统（必须用文字 hex，Figma Make 无法从图片读色）
| 角色 | 色值 | 用途 |
|---|---|---|
| 背景底色 | `#FFF8F3` 暖奶油白 | 全局页面背景 |
| 卡片背景 | `#FFFFFF` 纯白 | 卡片/弹窗/输入框 |
| 主品牌色 | `#F97316` 暖橙 | 主按钮、选中态、重点图标（点睛，不大面积铺） |
| 主色浅版 | `#FFEFE5` 暖橙 50 | 标签选中底、轻高亮、徽章 |
| 辅助色 | `#E8F5E9` 浅薄荷绿 / `#FFF3E0` 浅奶油橙 | 次要标签、成功态、装饰块 |
| 主文字 | `#1F2937` 深炭灰 | 标题/姓名/核心内容 |
| 次文字 | `#6B7280` 中灰 | 说明/小字档案/占位符 |
| 弱化线 | `#F3F4F6` 极浅灰 | 分割线/描边/输入框边框 |
| 长文正文 | `#333333` 深灰 | 双模态正文（非纯黑） |

### 9.3 布局原则
- 375px 基准，左右边距 20px。
- 三段式：顶部栏 / 中部滚动内容 / 底部固定主按钮。
- 卡片间距 16px，段落间距 24px；留白即内容。
- 信息自上而下流动：选择 → 补充 → 生成。

### 9.4 组件风格
- **圆角**：大卡片 20px / 小卡片·输入框 16px / 药丸·主按钮 999px（全圆角）。
- **卡片**：白底 + `0 4px 20px rgba(0,0,0,0.04)` 浅阴影，无粗边框。
- **标签药丸**：未选中白底+`#F3F4F6`边框；选中 `#FFEFE5`底+`#EA580C`字+小圆点。
- **主按钮**：深色 `#1F2937` 或暖橙 `#F97316` 底 + 白字 + 999px 圆角 + 高度 ≥48px。
- **次按钮**：白底 + `#F3F4F6` 边框 + `#1F2937` 字 + 16px 圆角。
- **星级**：暖橙填充圆角星形/心形，星间距 12px，点击区放大。
- **输入框**：白底 16px 圆角，聚焦边框转 `#F97316`，轻微上浮阴影。
- **插画**：小面积扁平线描，暖橙/浅绿点缀（登录页、空状态、结果页可用）。

### 9.5 字体层级（中文界面）
- 大标题（品牌/页标题）：`PingFang SC / system-ui`，20–24px，600 字重，`#1F2937`。
- 卡片标题（姓名/区块名）：16–18px，600，`#1F2937`。
- 正文（长文/语音）：15–16px，400，`#333333`，行高 1.6。
- 次要/小字（档案/占位/说明）：12–13px，400，`#6B7280`。

### 9.6 避免事项
- ❌ 直角 / 小圆角（<4px）、深色黑板主题、大面积高饱和橙底。
- ❌ 过多图标/徽章/装饰线、大段说明文字、机器感科技动效。
- ❌ 复杂表格/Excel 式列表；学生列表应是通讯录式卡片。
