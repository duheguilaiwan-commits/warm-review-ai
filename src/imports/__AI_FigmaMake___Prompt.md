# 暖评 AI · Figma Make 设计 Prompt（直接粘贴到 Figma Make 执行）

> 使用说明：本 Prompt 按 Figma Make（基于 Claude Sonnet 4）官方建议结构组织——**Task / Context / Key design elements / Expected behaviors / Constraints**。首次提示已尽量详细，直接整段粘贴即可。若某屏不满意，再用小提示逐屏微调。
> ⚠️ 重要：Figma Make 无法从图片精确读取颜色，所以下面所有颜色都已用**文字 hex**写明，请勿仅依赖参考图。

## ▶ 主 Prompt（整段复制）

```
请用 Figma Make 为我设计一款名为「暖评 AI（EduVibe）」的移动端 Web App 高保真 UI 原型。这是一款面向教培老师的 AI 点评工具：老师选学生、点标签、评星级、写一句话，AI 在 30 秒内生成一段高情商微信反馈 + 一段语音脚本，老师一键复制发给家长。整体气质要「温暖、轻盈、像一本干净的教师手账」。

【Task 任务】
生成一套 4 个屏幕的移动端高保真设计（iPhone 375px 宽度真机框），包含：登录页、学生列表页（首页）、打卡页（输入）、结果页（输出）。同时产出一套可复用组件（学生卡片、标签药丸、星级、主/次按钮、文本框、双模态卡片、FAB、底部固定按钮栏、弹窗）和色彩/字体变量。

【Context 上下文 / 页面流程】
流程：登录页 →（一键体验）→ 学生列表页 → 点学生卡片 → 打卡页 → 点「生成反馈」→ 结果页。核心操作不超过 3 个视窗。这是给非技术的老师用的，移动端碎片化场景，要一眼看懂、单手可操作。

【Key design elements 关键设计元素 / 逐屏模块】
1) 登录页：顶部品牌区（暖评 AI 文字 Logo + 轻量线描插画：老师手写/对话气泡/纸飞机）；中部一句 Slogan「把每一句点评，写成孩子愿意听的话」；一个大圆角「一键体验」主按钮（深色底白字）；邮箱登录入口默认弱化隐藏。底部极简版本小字。
2) 学生列表页（首页）：顶部固定栏写「暖评 AI」；下方学生卡片纵向列表。每张卡片只显示【头像首字圆形徽章（暖橙浅底）+ 学生姓名】，不显示性格底色；卡片右侧有「档案 ›」小字入口，点开弹出学生档案弹层（小字展示性格底色）。点卡片进入打卡页。右下角一个悬浮新建按钮 FAB（≥44px）。空状态时显示插画 + 「还没有学生，先添加第一位吧」。
3) 打卡页：顶部固定导航（返回箭头 + 学生姓名 + 「档案」小字入口）。中部：① 横向滑动分类 Tab（隐藏滚动条）：通用习惯 / 理科表现 / 文科表现 / 素质艺术 / 成人教育；每个 Tab 下是标签药丸矩阵可多选，末尾固定「+ 自定义标签」药丸。② 两张独立白色卡片分别放「课堂专注度」「课堂吸收度」各 1–5 星。③ 一个无极自适应高度文本框卡片，占位符「顺手记下一句话：今天他哪里卡壳了，或者哪里表现得不错…」。底部固定一个大圆角「生成反馈」主按钮。生成时显示骨架屏。
4) 结果页：两块白色大圆角卡片——「微信长文」(80–120字，深灰正文，自然换行) 和「语音脚本」(50–70字，口语化)。文字用流式打字机逐字出现 + 轻微光标。底部操作栏：「一键复制」主按钮 + 「换个说法」次按钮。触发 L3 限流时弹出一个柔性对话框，文案含「加开发者微信 Surge_forward_」和微信图标。

【Expected behaviors 交互预期】
- 标签药丸点击切换选中态（暖橙浅底）。
- 星级点击 1–5 切换填充。
- 主按钮固定在底部，不被内容遮挡。
- 滑动 Tab 平滑、无滚动条。
- 文本框随输入平滑增高。
- 结果页文字流式出现，有打字机光标。
- 弹窗/档案为居中浮层，带半透明遮罩。

【Constraints 约束】
- 设备/布局：Mobile-First，375px 基准宽度；考虑 iOS 底部安全区；所有可点区域 ≥44px（主按钮 ≥48px）；左右边距 20px；卡片间距 16px；三段式布局（顶栏 / 滚动内容 / 底部固定按钮）。
- 视觉风格：温暖极简（Warm Minimalism）。基调是「像美团/饿了么外卖 App 的暖橙卡片感」+「像携程/飞猪旅行 App 的极简留白」。大圆角、浅阴影、低信息密度、小面积暖橙点缀，绝不大面积高饱和橙底。
- 颜色（必须用这些值）：
  背景底色 #FFF8F3（暖奶油白）
  卡片背景 #FFFFFF（纯白）
  主品牌色 #F97316（暖橙，仅作点睛）
  主色浅版 #FFEFE5（标签选中底）
  辅助色 #E8F5E9（浅薄荷绿）/ #FFF3E0（浅奶油橙）
  主文字 #1F2937（深炭灰）
  次文字 #6B7280（中灰）
  弱化线 #F3F4F6（极浅灰）
  长文正文 #333333（深灰，非纯黑）
- 圆角：大卡片 20px / 小卡片与输入框 16px / 药丸与主按钮 999px（全圆角）。
- 阴影：卡片用 0 4px 20px rgba(0,0,0,0.04)，无粗边框。
- 字体（中文界面，用系统字体栈）：标题 PingFang SC / system-ui 20–24px 600；卡片标题 16–18px 600；正文 15–16px 400 行高1.6；小字 12–13px 400 灰色。
- 组件规范：
  主按钮：#1F2937 或 #F97316 底 + 白字 + 999px 圆角 + 高 ≥48px。
  次按钮：白底 + #F3F4F6 边框 + #1F2937 字 + 16px 圆角。
  标签药丸：未选白底+#F3F4F6 边框；选中 #FFEFE5 底+#EA580C 字+小圆点。
  星级：暖橙 #F97316 填充的圆角星形/心形，星间距 12px，点击区放大。
  输入框：白底 16px 圆角，聚焦边框转 #F97316 + 轻微上浮阴影。
- 避免：直角/小圆角、深色黑板主题、大面积高饱和橙、过多图标徽章装饰线、大段说明文字、机器感动效、Excel 式表格列表。
- 参考产品（请对齐其观感）：美团/饿了么外卖 App（暖橙卡片+底部大CTA）、携程/飞猪旅行 App（极简留白+浅阴影）、小红书首页（滑动 Tab）、主流 AI 聊天工具（流式深灰正文+打字机光标）。

请先生成全部 4 个屏幕的初版，再告诉我哪一屏需要微调。
```
